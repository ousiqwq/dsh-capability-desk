# 翻译模型同步与界面稳定性修复

2026-11-12，Capability Desk 1.3.4-local.4；保持现有图标、尺寸和布局 CSS。Soul Desk 与 File Bridge 本轮只做回归，不改运行代码。

## 修复范围

- 实时订阅 DSH 原生当前会话及 ModelDirectory 状态，切换会话、模型或推理强度时立即同步，并在请求前重新读取。没有写死任何提供商或模型。
- 原生目录确认旧会话模型不可用时，翻译跟随 DSH 当前默认模型并显示说明，不修改会话的模型选择。服务端也不会被已移除的隐式旧会话来源阻塞；明确传入的无效模型会返回原因。
- 单项翻译第一次使用顶部原生小提示，不调用模型；已有缓存时可同时切换查看。3.5 秒内再次点击强制翻译，包含中文、同语言及已缓存的条目。独立重新翻译图标仍直接执行；快速重复事件只发出一次请求。
- 提示互斥，避免保存成功与再次点击提醒叠在一起。进度也使用顶部原生 Toast，不向列表上方插入一行内容。
- 切换模型、范围和语言时保留原列表，加载完成前禁用操作，避免清空列表造成设置窗口缩放或滚动跳动。
