# 三个插件的原生界面复用检查与修改计划

2026-11-12。检查当前源码与本机 DSH 0.2.2-rc.2 的公开 UI primitives。Capability Desk 1.3.3、File Bridge 0.2.2 的 client.js 在本次修改前分别与本机 1.3.1、0.2.0 逐字节相同，结论适用于这两份已发布代码及本机安装。Soul Desk 检查版本为本机 0.4.1-local.2。初次交付先实施范围下拉；用户随后已确认执行完整计划。当前三个插件均已完成下述原生控件迁移、联合验收和本机安装；未推送 GitHub/npm。

## 判断标准

- **原生组件**：直接使用 DSH 的 Button、Menu、Switch、Input、SegmentedTabs、Tooltip、Toast 等，交互、焦点和主题随宿主维护。
- **主题令牌复用**：HTML 控件或自定义布局使用 DSH 语义色、字号、圆角变量。能够跟随主题，但控件行为和样式仍由插件维护。
- **自绘**：插件自行实现控件边框、选中态、悬停、焦点、弹层，或写死颜色。浏览器原生 HTML select 不等于 DSH 原生 Menu。

## 初始检查结论（迁移前）

| 插件 | 已复用 DSH 原生组件 | 仍为自定义部分 |
| --- | --- | --- |
| Soul Desk | 主要操作按钮、人设菜单、注入模式菜单、全局/工作区分段选择、总开关、记忆搜索输入、Tooltip 和 Toast | 人设名称仍是 HTML input；正文/记忆 textarea；记忆类别和导入策略 select；部分标签页、卡片、徽标及布局。主要颜色已使用 DSH 令牌 |
| Capability Desk | 本轮新增范围选择的 Button、Menu、箭头图标；原有设置入口与语言服务使用宿主接口 | 其他按钮、checkbox、规则 select、搜索和翻译输入、能力页签、翻译图标与状态提示仍自绘。存在写死颜色及直接覆盖宿主设置弹窗/导航 DOM 的窄屏 CSS |
| File Bridge | 原生下载图标、Tooltip、侧栏文档操作插槽与 i18n | 下载按钮及展开按钮自行实现；错误气泡自绘，带颜色/阴影回退；布局和无障碍播报由插件维护 |

对应代码：各项目的 `client.js`。业务排版和卡片分组可以保留必要 CSS；组件外观、焦点与交互优先交由 DSH 原生实现。

## 本轮实施：Skill 与 MCP 的范围选择

- 用 DSH Button + Menu 替代 HTML select。
- 收起时显示全局默认或工作区名称；展开后工作区名称与路径分行，路径为 11px 淡色注释，可换行。
- 使用原生选中勾、键盘操作、浮层定位；保留全局入口、现有范围值和重新发现功能。
- 工作区仍以原有规范路径为规则身份，改名只改变名称；旧 HTTP 结果不覆盖侧栏实时名称。
- 只为布局设置宽高、间距、截断和注释排版；新原生按钮排除在旧自绘按钮样式之外。
- 本机以 1.3.4-local.1 安装，后端文件与原安装逐字节相同。规则、扫描来源、MCP 批准、翻译缓存保持原数据。

## 已实施范围

### 1. Capability Desk：优先迁移交互控件

1. 统一按钮为 Button，boolean 选项为 Switch，搜索/路径/翻译目标为 Input；保留 datalist 的语言建议与现有值。
2. 单项能力规则 select 改为 Menu，保持继承/启用/停用的语义和 MCP 审批流程。
3. Skill/MCP 页签改为 SegmentedTabs；翻译操作复用原生按钮和合适图标，并保持缓存切换不发模型请求。
4. 状态、错误、进度颜色改用 DSH 语义令牌；提示使用公开的原生提示组件。
5. 移除对 `[data-shortcut-modal="settings"]`、nav 等宿主内部结构的覆盖，插件只处理自身容器的响应式布局。

验收：全局/工作区规则、继承及明确停用，MCP 批准/连接/撤销，翻译缓存和强制翻译，工作区实时改名，键盘、窄屏、深浅主题、i18n。先在独立 DSH_HOME 使用本地夹具，再部署。

### 2. File Bridge：迁移下载操作与错误提示

1. 28px 下载操作改为原生 Button ghost/sm，展开操作改为 Button outline；仅保留必要的图标尺寸和布局。
2. 继续使用现有原生图标与 Tooltip，将错误气泡迁移到公开提示组件或 MenuSurface，保留无障碍错误播报及再次点击重试。
3. 清理重复的边框、hover、focus 和颜色/阴影回退。

验收：普通文件与大文件下载摘要一致、重复点击保护、失败重试、取消/切换文件、过期和已变更文件、权限失败、不可预览文件，以及原生表格/Markdown 预览。

### 3. Soul Desk：补齐剩余控件

人设名称改为 Input；记忆类别和导入策略改为 Menu；人格/记忆页签评估改为 SegmentedTabs。当前公开 primitives 未提供独立 Textarea，正文编辑保留语义 HTML textarea 并使用宿主令牌。卡片分组与响应式排版保留业务布局 CSS。

验收：未保存草稿、记忆分类/编辑/导入预览和修订冲突；保留已完成的人设实际注入、切换、记忆归属、子代理和冷恢复检查。

## 数据保护与发布

每步单独打包，在安装前备份 profile 和数据；比对规则/批准/缓存以及原有会话、人设、记忆。功能接口与业务数据结构不随样式迁移改变。本次按用户确认实施三个插件的控件迁移，保持本地安装，不发布远端版本。
