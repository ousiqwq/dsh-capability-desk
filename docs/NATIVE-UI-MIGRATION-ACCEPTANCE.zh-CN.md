## 自动测试与真实宿主验收

- 103 项已有自动测试通过：能力插件 56 项、灵魂 31 项、文件下载 16 项；新增语言键另行通过字典检查。
- 使用独立 DSH_HOME、合成 Skill/记忆、测试 stdio MCP 与本地模型夹具，未使用真实私人会话测试或调用外部付费模型。
- 能力控件：默认开关、全局启用/禁用/使用默认、工作区覆盖/继承；语言输入保存及刷新恢复；缓存译文切换不调用模型，单项强制翻译更新缓存；实际 MCP 批准、连接、工具调用与禁用断开。
- 能力界面：九种宽度下选择框和按钮对齐，无横向溢出；原生菜单键盘选择；连续工作区改名和旧 HTTP 回包场景均保留实时名称及规则路径。
- 灵魂：真实模型请求中检查三层规则、人设及记忆切换、none/follow、三种注入模式、总开关和子代理隔离。浏览器对话菜单选择确实用于下一次模型请求。
- 编辑器：名称输入、跨页签保留未保存草稿、记忆分类/筛选/搜索/编辑版本、修订冲突保留草稿与重新读取；整体导出、两种导入选项选择及实际 merge 导入保留原人设和默认。
- File Bridge：5 类下载逐字节摘要校验，包括中文文件名、二进制、空文件及 34,603,015 字节文件；原生表格/Markdown 预览、深浅主题、键盘下载、错误 Toast 和再次下载重试；来源权限边界仍有效。
- 页面没有脚本错误。报告与截图留在各项目忽略的 test-results 目录；合成测试会话在下载验收结束时归档。

## 安装与保护

安装前停止空闲服务，保存完整 DSH_HOME、原 profile、灵魂库和能力策略/翻译缓存及会话摘要清单。部署脚本对比：全部人设与记忆、每个会话的自身/子代理规则和派生决定、工作区默认、全局设置；能力策略、MCP 批准、翻译缓存、原配置文件及旧备份逐字节一致；全部原生会话压缩档案不变；其他 profile 依赖不变；安装文件与测试包逐字节一致。失败立即成套恢复旧 profile 和相应数据。

联合安装与后续只读核验记录位于 Capability Desk 的 `test-results/native-all/`。本机备份保留于 DSH restore/backups，备份目录权限 0700，不纳入公开包或 Git。
