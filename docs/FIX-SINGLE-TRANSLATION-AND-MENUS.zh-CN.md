# 单击翻译、缓存显示与菜单定位验收

本轮安装：Capability Desk 1.3.4-local.5、Soul Desk 0.4.1-local.4。File Bridge 保持 0.2.3-local.1，运行代码未改。宿主为当前 DSH 0.2.2-rc.2；不推送 GitHub/npm。

## 已确认的行为

- 每个条目只保留一个 28px 文字翻译图标。单击立即使用当前原生模型强制重新翻译，中文、英文、同语言及已有缓存的条目一致处理；移除独立刷新图标、两次确认和查看缓存的点击动作。
- 页面默认直接显示有效缓存，忽略旧的浏览器隐藏偏好。打开、刷新、切换模型和重启均不会为显示缓存调用模型；显示译文开关仍能主动切换原文。
- 只有批量“翻译当前列表”复用缓存并判断同语言跳过。单项按钮始终重新生成并更新对应显示缓存。
- 在保留全部原有模型相关缓存记录的基础上，新增按原文和目标语言识别的显示索引。旧条目可用 DSH 原生历史模型信息补建引用；源文或目标语言变化不会误用旧译文。文件仍为兼容的 version 2，原记录和旧版记录不重置。
- 能力和灵魂的菜单继续使用 DSH 原生 Menu、样式和键盘交互，仅由各自按钮的实际坐标定位弹层；不依赖 CSS 锚点来决定位置。真实滚动时关闭，点外/缩放时关闭；忽略打开前已经完成的程序滚动，避免刚打开就消失。移动、内容更新及边界避让都保持对应按钮。
- 保留路径字号、按钮尺寸、卡片布局、顶部原生提示以及已有规则、人设和文件下载功能。

- 106 项自动测试：能力 59、灵魂 31、文件 16。新增旧版缓存无模型调用迁移、离线显示、跨模型复用和强制更新后恢复测试。
- 浏览器逐项测量多个规则行、灵魂模式、人设、记忆菜单的弹层与按钮坐标；三种宽度下验证菜单归属、边界、滚动与点外关闭。规则选择验证只有目标条目改变。
- 验证旧隐藏偏好下的自动显示、中英文单击、原生模型实时切换、批量缓存命中、单项重新生成、顶部进度不挤动列表，以及重启后直接恢复最新译文且模型调用为零。
- 能力控件、MCP 批准/连接/实际调用/禁用、工作区覆盖/继承、语言设置、九种宽度、名称改动与旧 HTTP 回包、键盘及深浅主题通过。
